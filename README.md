# jnm-2027
Site des Journées Nationales MIAGE 2027 — 26 au 28 mai 2027, Polytech, Université Lyon 1.

- `index.html` : la page du site
- `style.css` : la mise en forme

Pour voir le site : ouvrir `index.html` dans un navigateur.
Pour le publier : Settings → Pages → branche `main`, dossier `/ (root)`.
